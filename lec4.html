Lesson 4: Paragraphs, Block vs. Inline & Semantic Metadata

Understand flow layouts, block vs inline behaviors, abbreviations, addresses, and bidirectional text overrides.

1. Block-Level vs. Inline Elements

Block-level elements (e.g. <p>, <div>, <h1>) always start on a new line and stretch to occupy the full available width.

Inline elements (e.g. <span>, <a>, <strong>, <em>) only occupy as much width as necessary and flow inside existing lines.
