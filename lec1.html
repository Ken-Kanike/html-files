Lesson 1: HTML5 Architecture & Document Fundamentals

Mastering the standard HTML boilerplate, tag syntax, rendering flow, and commenting conventions.

1. Anatomy of an HTML5 Document

Every modern web page begins with the <!DOCTYPE html> declaration which informs browsers to render in standards-compliant HTML5 mode.

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Page Title</title>
  </head>
  <body>
    <h1>Hello World</h1>
    <p>Welcome to modern web development!</p>
  </body>
</html>

2. Container Tags vs. Void (Self-Closing) Tags

Container Tags Require both an opening and closing tag with content nested inside: <p>content</p>, <div>...</div>.

Void Tags Have no closing tag or internal text nodes: <br> (line break), <hr> (horizontal rule), <img> (image), <input>.

3. Code Commenting Conventions

Comments are ignored by browser rendering engines but are essential for documenting logic, structuring sections, and collaborating with team members.

<!--
  Multi-line Comment:
  Section: Header Navigation
