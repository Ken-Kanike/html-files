Lesson 2: Typography, Headings & Semantic Text Elements

Explore heading hierarchy, semantic text emphasis, mathematical notation, and HTML entities.

1. Heading Hierarchy (<h1> through <h6>)

Search engines and screen readers use headings to understand document structure. Always use a single <h1> per page for the primary topic.

Heading 1 (<h1>) - Main Document Title

Heading 2 (<h2>) - Major Section

Heading 3 (<h3>) - Sub-section

Heading 4 (<h4>) - Sub-topic

Heading 5 (<h5>) - Minor Topic
Heading 6 (<h6>) - Smallest Heading

2. Semantic Text Formatting Tags

<strong> / <b>:

Strong importance / Bold text

<em> / <i>:

Emphasized voice / Italic text

<mark> (Highlight):

Highlight with <mark> tag

<del> & <ins>:

$99.00 $49.00

<sub> (Subscript):

Chemical Formula: H2O, Glucose: C6H12O6

<sup> (Superscript):

Math Notation: E = mc2, Pythagorean: a2 + b2 = c2

3. HTML Character Entities

Reserved characters in HTML must be represented using special character entities to prevent parser confusion:

&lt; → < (Less Than)

&gt; → > (Greater Than)

&amp; → & (Ampersand)

&copy; → © (Copyright symbol)

&nbsp; → Non-breaking whitespace (      spaced)
