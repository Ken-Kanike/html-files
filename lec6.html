Lesson 6: Hyperlinks, Document Navigation & Anchor Protocols

Relative paths, external URLs, security attributes (noopener noreferrer), bookmark anchors, and protocol handlers.

1. Relative vs. Absolute URLs

Relative URLs link to files located on the same server/repository (e.g. lec7.html or coak/index.html).

Absolute URLs specify the complete protocol and domain (e.g. https://developer.mozilla.org/).

<!-- External link with security best-practice attributes -->
<a href="https://github.com" target="_blank" rel="noopener noreferrer">GitHub Official</a>

<!-- Internal Relative link -->
<a href="lec7.html">Proceed to Tables Lesson</a>

<!-- In-page Bookmark Anchor Jump -->
<a href="#target-section">Jump to Section</a>
