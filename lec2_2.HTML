Lesson 2.2: Modern CSS Background Techniques

Learn how to construct solid colors, linear/radial gradients, background images, and fixed parallax covers.

1. CSS Background Properties

/* Full-screen responsive background image with dark gradient overlay */
body {
  background: linear-gradient(rgba(0,0,0,0.7), rgba(0,0,0,0.9)),
              url('wallpaper.jpg');
  background-size: cover;          /* Scales image to cover entire viewport */
  background-position: center;     /* Centers the image */
  background-repeat: no-repeat;    /* Prevents tiling */
  background-attachment: fixed;    /* Parallax effect on scroll */
}
