## 🏆 Flagship Capstone Project: Coca-Cola "Real Magic" Experience

**Live Demo:** 👉 **[Launch Coca-Cola Real Magic Experience](https://ken-kanike.github.io/html-files/coak/index.html)**  
**Source Code:** [`coak/index.html`](coak/index.html) | [`coak/style.css`](coak/style.css) | [`coak/script.js`](coak/script.js)

The culmination of all HTML5, CSS3, and JavaScript learnings into an immersive brand landing page featuring:
- 🎬 **Precision Section-Driven 3D Bottle Physics**: Viewport intersection tracking smoothly guides the bottle into dedicated columns without overlapping headings, buttons, or cards on any monitor resolution.
- 🫧 **Real-Time Effervescence Canvas**: Micro-carbonation bubbles and floating frosted ice cubes with lighting effects.
- 🎨 **Interactive Flavor Spectrum**: Real-time flavor switcher (Original, Zero Sugar, Cherry Splash, Vanilla Dream) that dynamically transforms the scene's neon aura and nutrition cards.
- 🥤 **Share-A-Coke Studio**: Live customizer where users can type any name and generate a personalized Coke can edition.
- ❄️ **Sub-Zero Chill Simulator**: Interactive temperature slider (1°C to 12°C) with real-time sensory feedback.
- 💼 **Franchise ROI Calculator**: Interactive volume distribution slider with instant gross margin calculation.
- 🔊 **Web Audio API Sound FX**: Multi-tone bottle cap pop and effervescence hiss audio synthesizer.
- 📱 **Full Interactive Suite**: Glassmorphic accordions with nutrient macro bars, 3D mouse parallax cards, slide-out drawer navigation, search modal, and cold pack ordering sheet.

## 🚀 Quick Start & How to Run

Because this repository is built with standard HTML5, CSS3, and JavaScript, no compilation or build steps are required.

### Method 1: Instant Online Access
Visit the live deployment at: **[https://ken-kanike.github.io/html-files/](https://ken-kanike.github.io/html-files/)**

### Method 2: Live Server (VS Code Extension)
For local development with hot-reloading:
1. Open this repository folder in **VS Code**.
2. Install the **Live Server** extension (`ritwickdey.LiveServer`).
3. Right-click on `coak/index.html` and select **"Open with Live Server"**.

### Method 3: Local Python HTTP Server
Run a lightweight HTTP server using Python in the project root:
```bash
# Python 3.x
python -m http.server 8000
```
Then navigate to `http://localhost:8000/` in your browser.
